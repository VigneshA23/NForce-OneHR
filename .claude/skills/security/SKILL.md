# /security

Use this for changes involving:
- employee data
- APIs
- permissions
- authentication
- attendance/leave changes
- approvals
- exports/downloads
- file uploads
- administrative actions

Run the security-reviewer agent.

Do not modify files during the initial review.

Focus on realistic vulnerabilities in the changed code.
