# Security regression suite for ConfidentialityGuard (ai-security/guard-patterns.txt).
#
# Every line under "## refuse" must be declined before the model is called, and every line under
# "## answer" must reach it. "\n" in a line is a line break; {ZWSP} is a zero-width space.
#
# Deliberately absent from "refuse": questions the structure already makes harmless, so refusing
# them would only make the assistant brittle - other people's salaries, leave or PII (no provider
# returns them to a role that may not see them), capability questions about actions ("can you
# delete records" - it explains it is read-only), "convert it into YAML" follow-ups (a refused turn
# is never written to the conversation, so "it" is the last real answer), and pleading or pressure
# with no request attached. Those are exercised live, against the model.
